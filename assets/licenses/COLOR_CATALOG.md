# Цветной каталог — этап 011, 1 октября 2026

## Состав и воспроизводимость

109 разных изображений: **80 категорий + 20 финансовых + 9 банков**.
Категории: общее 1; еда 11; транспорт 10; путешествия 5; дом 10;
покупки и уход 6; здоровье и спорт 6; семья и обучение 4; досуг 8;
техника и связь 3; бизнес 10; доходы 6.
Финансовые: наличные 9; счета и накопления 11.
В выборе кошелька также сохранены 10 прежних ID целей: они повторно используют
изображения этого набора и **не увеличивают число уникальных изображений**.
В итоге выбор категории содержит 80 вариантов, выбор кошелька — 39.

Обычные изображения — [Microsoft Fluent Emoji, Flat](https://github.com/microsoft/fluentui-emoji),
commit `1ffb34c752ecf5d402f04cfb4b392c77f57c54bc`, лицензия MIT,
полный текст в `Fluent-Emoji-LICENSE.txt`. Это фиксированные локальные SVG,
а не Unicode-символы и не системный emoji-шрифт. Геометрия и цвета оригинальные.
Названия, русские синонимы и смысловое назначение — метаданные приложения.
Некоторые назначения метафорические: замок для сейфа, свинка для копилки,
коробка для депозита. Денежный знак на рисунке не задаёт валюту кошелька.

Точные URL каждого SVG, SHA-256 и MIT записаны в `assets/icons/catalog.json`.
`tools/icon-seeds.csv` — исходные подписи/группы/синонимы.
`tools/fetch-fluent.ps1` получает файлы из зафиксированной версии,
`tools/generate-icon-catalog.ps1` генерирует Dart-каталог из манифеста.
Для повторной загрузки дерева: GitHub API
`https://api.github.com/repos/microsoft/fluentui-emoji/git/trees/1ffb34c752ecf5d402f04cfb4b392c77f57c54bc?recursive=1`;
сохранить ответ в `build/icon-sources/fluent-tree.json`.
После генерации выполнить `dart format lib/icon_catalog.dart`.

## Банки: источники и условия

Банковские знаки **не покрываются MIT набора Microsoft**. Права на товарные
знаки принадлежат соответствующим владельцам. Использование здесь — обозначение
выбранного пользователем банка, без заявления о партнёрстве. Наличие файла на
официальном сайте не означает открытую лицензию. Общего разрешения на
коммерческое распространение всех банковских знаков не установлено; перед
публичным выпуском нужно урегулировать применимые условия у правообладателей.
Это описание найденных условий, не утверждение о полученном разрешении.

Точные адреса загруженных файлов и SHA-256 находятся в
`assets/icons/banks/sources.json`. Нижеследующие страницы объясняют происхождение.

Для части российских доменов Windows не доверяет цепочке TLS; публичные
бренд-файлы скачаны отдельными запросами curl с локальным `-k`, без авторизации.
Настройки системы/приложения не менялись. Образцы сверены визуально и с
указанными публикациями; HTML ответов хранится только в build/icon-sources.

Не включены: **ВТБ** (сайт не отдал пригодный ресурс), **Freedom Bank**
(HTTP 403), **ForteBank** (найденный favicon всего 16×16, недостаточная плотность;
полная надпись на сайте не подходит для квадратного значка 24–40 px).
Подмены этих банков буквами или случайными рисунками нет.

## Отображение и совместимость

Все SVG/PNG и лицензии включаются в Flutter assets. При показе истории сеть
для изображений не используется. `icon_id` никогда не преобразуется в URL.
Неизвестный ID кошелька — стандартный кошелёк, категории — нейтральная бирка;
исходное неизвестное значение сохраняется, пока пользователь не выберет другое.
Все 35 прежних wallet ID поддерживаются. Миграция 011 не обновляет кошельки.
Изменение картинки под старым ID не меняет записи операций или квитанции.

Контрольный лист `build/qa/color-catalog.png` показывает каждое из 109 изображений
при 24, 32 и 40 px. Проверки также охватывают узкую сетку, поиск по синонимам,
три уровня категории, сохранение/повторную загрузку и актуальные значки истории.
