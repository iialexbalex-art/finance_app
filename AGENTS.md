# Работа в finance_app

Перед каждой новой задачей изменения исходников выполните проверяемую точку
возврата: `python tools/project_checkpoint.py create --label "Название задачи"`.
Если python отсутствует в PATH, используйте установленный Python или uv.
Команда должна закончиться успешно до правок. Оригинальные assets сохраняются
по SHA-256, повторные версии не дублируют одинаковые байты. Не меняйте качество.

Перед применением SQL используйте `tools/apply_backup_migration.py`: он требует
свежий проверенный административный дамп БД и создаёт checkpoint программы.
Не запускайте старые seed/установщики. Не откатывайте рабочие данные ради тестов.
Секреты не включайте в экспорт/репозиторий. `.local-backups` — приватные файлы.
Локальная точка возврата не заменяет независимое серверное хранилище.
